# Casino Hold'em

Казино-покер против дилера на чистом HTML/CSS/JS, без сборки и зависимостей.

**Играть:** https://dimmik.github.io/casino-holdem/

Можно и локально — просто открыть `index.html` в браузере.

## Правила

1. Ставите **Анте** (и, по желанию, боковую **AA Bonus**), нажимаете «Раздать».
2. Вам — 2 карты, дилеру — 2 закрытые, на стол — флоп (3 общие карты).
3. **Фолд** — теряете Анте. **Колл** — ставите ещё 2× Анте.
4. Открываются терн и ривер, дилер вскрывается; у каждого лучшая комбинация из 5 карт из 7.
5. Дилер играет с **парой четвёрок или выше**:
   - не квалифицировался — Анте платит по таблице, Колл возвращается;
   - вы сильнее — Анте по таблице, Колл 1:1;
   - дилер сильнее — проигрываются обе ставки;
   - ничья — ставки возвращаются.

| Анте | Выплата |
|---|---|
| Роял-флеш | 100:1 |
| Стрит-флеш | 20:1 |
| Каре | 10:1 |
| Фулл-хаус | 3:1 |
| Флеш | 2:1 |
| Стрит и ниже | 1:1 |

**AA Bonus** — по вашим 2 картам и флопу, выплачивается даже после фолда:
роял-флеш 100:1, стрит-флеш 50:1, каре 40:1, фулл-хаус 30:1, флеш 20:1,
стрит / тройка / две пары / пара тузов 7:1.

Баланс и статистика хранятся в `localStorage` браузера.
